# Ataa: Your Donation Hub

Create a modern Arabic web application called “Ataa” for managing monthly donations for a Hussaini Mawkib.

The application should support Arabic language with full RTL layout.

Create the following pages only:

Login Page

Admin Dashboard

Donors List

Add Donor Page

Donor Details Page

Donor Dashboard

Use a modern, clean UI with green, black, white, and gold colors.

Do not add payment gateways or WhatsApp integration.
